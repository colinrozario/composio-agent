How the list was made

An agent does the research. Automated checks catch invented or wrong answers. People review a sample.

Catalog

Composio's toolkit catalog is pulled and matched against the 100 apps, so "already built" is a fact, not a guess.

Research

For each app the agent searches, reads the developer docs and fills 12 fields. Each field gets a source URL and a confidence level.

Checks

Every cited link is fetched. Auth is compared with Composio's catalog. Fields that look weak are re-asked using only the page text.

Review

A second model answers the same questions independently. People grade a random sample to measure accuracy.
