      How it works

      An agent does the research, automated checks catch invented or wrong answers, and people review a sample.

      1. Check the catalog

        Composio's toolkit catalog is matched against the 100 apps, so "Composio has it" is a fact, not a guess.

      2. Research each app

        The agent searches, reads the developer docs and answers 12 questions. Every answer gets a source link and a confidence level.

      3. Check the answers

        Every cited link is opened. Sign-in methods are compared with Composio's catalog. Weak answers are asked again using only the page text.

      4. Review by people

        A second model answers independently, and people grade a random sample to measure accuracy.
