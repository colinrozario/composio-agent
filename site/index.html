The agent

Python pipeline, one web-search agent call per app, then four independent checks. Raw outputs are append-only, so pass 1 is never overwritten.

  1. Seed and catalog100 apps, strict schema, Composio toolkit catalog pulled for gap analysis.
  2. Pass 1 researchWeb-search agent fills 12 fields, each with confidence and a source URL.
  3. Verification loopsLink check, Composio auth oracle, grounded re-ask on page text only, second model with a rephrased prompt.
  4. Human reviewStratified sample: 2 random per category plus every flagged app. Field-level truth with sources.
  5. Grade and publishPass 1 and automated final graded on the same truth. Human corrections ship but are not counted.
